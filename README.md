# odin-message-board

A simple message board application where users can post and view messages. This project is developed as part of The Odin Project's NodeJS/Express curriculum to practice the Model-View-Controller (MVC) architectural pattern.

## Technologies Used

- Node.js
- Express
- EJS (Embedded JavaScript templates)

## Getting Started

### Prerequisites

- Node.js installed on your machine

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/mostafa-imam/odin-message-board.git
   ```
2. Navigate into the project directory:
   ```bash
   cd odin-message-board
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

### Running the Project

Start the server by running:

```bash
node app.js
```

The application will be available at `http://localhost:3000`.
